# Захват территории — правила для участника

Ты создаёшь команду для турнира один на один в игре «Захват территории». Соперник — команда другого участника, его код тебе неизвестен. Бой показывают на видео: важен и результат, и то, как выглядит твоя команда.

Работай только внутри этой папки. Твоя команда — папка `bot/`: при подведении итогов из неё берутся `bot.js`, `team.json` и `skin.js`, остальное организуй как хочешь. Папку `arena/` не меняй: судья использует свою копию движка, правки в твоей копии на бой не влияют.

## Игра

- Поле 64×40 клеток, x вправо, y вниз, клетка `(x, y)` в плоских массивах лежит по индексу `y * 64 + x`.
- У каждого стартовая база 3×3. Базы стоят симметрично относительно центра поля, поэтому стороны равны.
- Каждый ход твоя голова сдвигается на одну клетку. 10 ходов в секунду, раунд — 120 секунд (1200 ходов).
- Пока ты на своей земле, следа нет. Сошёл со своей земли — за тобой тянется хвост. Вернулся на свою землю — хвост и всё, что он обвёл вместе с твоей землёй, становится твоим, в том числе земля соперника. Обведённым считается всё, до чего нельзя добраться от края поля, не пересекая твою землю и хвост.
- Наехал на чужой хвост — хозяин хвоста погибает. Наехал на свой хвост — погиб сам. Вышел за край поля — погиб.
- Головы столкнулись (въехали в одну клетку или поменялись клетками) — выживает тот, кто въезжал на свою землю; на нейтральной или чужой земле гибнут оба.
- Погиб — хвост исчезает, сгорает вся твоя земля, кроме базы. Через 3 секунды возрождаешься на базе.
- База 3×3 неприкосновенна: её нельзя захватить, она всегда твоя.
- Развернуться на 180° за один ход нельзя: такая команда считается «прямо».
- По истечении 120 секунд побеждает тот, у кого больше доля поля. Поровну — ничья.
- Три карты: Диагональ, Фланги, Ближний бой — отличаются положением баз. Матч — серия раундов до нескольких побед. Каждая карта играется два раунда подряд, стороны меняются каждый раунд.

## Что сдать

`bot/bot.js` — ES-модуль:

```js
export default {
  init(info) {},             // необязательно, в начале каждого раунда
  tick(state) { return 'up'; }, // 'up' | 'down' | 'left' | 'right' | 'straight'
};
```

Бот исполняется в браузере внутри Web Worker, а в песочнице — в Node. Нельзя использовать DOM, Node-модули, сеть и внешние пакеты. Можно импортировать свои файлы из `bot/` относительными путями и `../arena/engine.js`. Модуль загружается один раз на раунд турнира и один раз на матч, поэтому состояние между раундами матча можно хранить в переменных модуля. Лимит на один `tick` — 50 мс; не успел — голова едет прямо. Ошибка в `tick` — тоже прямо. Около 3 секунд без ответа — бот отключается до конца матча, голова едет прямо.

`bot/team.json` — имя и цвета команды:

```json
{ "name": "Имя команды", "motto": "Девиз", "color": "#e8825a", "accent": "#ffe2c4" }
```

Имя до 24 символов и девиз до 80 символов покажут крупно. `color` — основной цвет команды (счёт, рамки, частицы), `accent` — второй.

`bot/skin.js` — облик команды, см. ниже.

## Что видит бот

Каждый ход `tick(state)` получает всё поле, скрытого нет:

```js
{
  tick, time, timeLeft, ticksLeft, tickRate, side, width, height, mapName,
  land:  [...],   // W*H: 0 — ничья, 1 — твоя земля, 2 — земля соперника
  trail: [...],   // W*H: 0 — нет хвоста, 1 — твой хвост, 2 — хвост соперника
  me: {
    x, y, dir,              // голова и текущее направление
    alive, respawnIn,       // жив ли; ходов до возрождения
    home,                   // стоит ли голова на своей земле
    trail: [{ x, y }],      // хвост по порядку от начала, trailLength — его длина
    cells, percent,         // земли в клетках и в процентах поля
    base: { x, y },         // центр базы
    kills, deaths,
  },
  enemy: { ...то же для соперника },
}
```

`init(info)` получает `{ round, side, mapName, view }`, где `view` — такое же состояние на старте раунда. Точные правила — в `arena/engine.js`, его можно читать и импортировать для своих расчётов.

## Облик

`bot/skin.js` — ES-модуль с четырьмя функциями рисования. Арена нейтральная и почти бесцветная: на экране видны твой персонаж, узор твоей земли, твой хвост и твоя анимация победы.

```js
export default {
  head(ctx, { size, dir, frame, frames, color, accent }) {},
  land(ctx, { size, color, accent }) {},
  trail(ctx, { size, color, accent }) {},
  victory(ctx, { width, height, t, duration, color, accent, name }) {},
};
```

- `head` — голова или персонаж, который ездит по полю и смотрит с карточки команды. Рисуй в квадрате `size×size` с центром в `(size/2, size/2)`, лицом в сторону `dir` (`up`, `down`, `left`, `right`). Это цикл движения из `frames` кадров (8 кадров на 0,8 секунды), `frame` — номер кадра. На поле персонаж занимает примерно 2,5 клетки, на карточке перед боем — почти половину высоты экрана, там `dir` = `down`.
- `land` — узор твоей земли: квадратная плитка `size×size`, которая повторяется без швов. Одна клетка поля — четверть плитки (`size / 4`).
- `trail` — узор хвоста, такая же плитка. Хвост должен хорошо читаться поверх любой земли.
- `victory` — анимация победы раунда, примерно на треть экрана: кадр в момент `t` секунд от 0 до `duration` (около 4 секунд), холст `width×height` в пропорции 16:9. Каждый кадр рисуется на чистом прозрачном холсте.

Всё рисуется в отдельном Web Worker на OffscreenCanvas через обычный Canvas 2D (`ctx` — это `OffscreenCanvasRenderingContext2D`). Нет DOM, сети, картинок с диска и внешних шрифтов: рисуй кодом. Можно импортировать свои файлы из `bot/`. Облик не влияет на бой. Если функция бросила ошибку, ничего не вернула вовремя (около 0,3 секунды на кадр) или облик завис, вместо него покажут простой облик по умолчанию, бой продолжится.

Посмотреть облик и бой глазами: просмотрщик в корне арены (`node serve.mjs` в папке выше), если он доступен. Проверить без браузера, что облик хотя бы загружается и не бросает ошибок, песочница не умеет: рисование проверяй внимательно.

## Раунды с доработкой

Турнир может идти в режиме доработки: после каждого раунда просмотрщик останавливается и пишет в папку `rounds/` этой папки два файла:

- `rounds/round-N.md` — короткая сводка: итог, доли поля по времени, где и как ты погибал, что делал соперник;
- `rounds/round-N.json` — полный реплей: все ходы обеих сторон.

Разобрать реплей без браузера:

```
node arena/replay.mjs rounds/round-1.json               # сводка и карта поля каждые 30 секунд
node arena/replay.mjs rounds/round-1.json --at 47       # карта поля на 0:47
node arena/replay.mjs rounds/round-1.json --events      # все гибели и захваты
node arena/replay.mjs rounds/round-1.json --from 40 --to 45   # ходы обеих сторон по тикам
```

Следующий раунд начинается со свежей загрузкой `bot/` с диска.

## Песочница

```
node arena/cli.mjs                     # bot/ против Охотника, 6 раундов: все карты с обеих сторон
node arena/cli.mjs --vs farmer         # против Пахаря
node arena/cli.mjs --vs bot            # зеркальный матч против самого себя
node arena/cli.mjs --rounds 2 --map Фланги --verbose
node arena/cli.mjs --save sandbox      # записать реплеи и сводки в sandbox/ для replay.mjs
```

Спарринг-боты лежат в `arena/sparring/`: «Пахарь» аккуратно нарезает прямоугольники, «Охотник» делает короткие вылазки и режет чужие хвосты. Нужен Node.js 18+.
