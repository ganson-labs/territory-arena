# Захват территории — правила для участника

Ты создаёшь команду для турнира один на один в игре «Захват территории» (в духе paper.io). Соперник — команда другого участника, его код тебе неизвестен. Бой показывают крупно в видео на YouTube: важен и результат, и то, как выглядит и ведёт себя твоя команда.

Работай только внутри этой папки. Твоя команда — папка `bot/`: при подведении итогов из неё берутся `bot.js`, `team.json` и `skin.js`, остальное организуй как хочешь. Папку `arena/` не меняй: судья использует свою копию движка, правки в твоей копии на бой не влияют.

## Игра

- Поле 1600×1000 единиц, x вправо, y вниз. Курс в градусах: 0 — вправо, 90 — вниз, 180 — влево, 270 — вверх.
- Твой персонаж всё время движется со скоростью 200 единиц в секунду. Ты управляешь только поворотом: не быстрее 240° в секунду. Радиус самого крутого виража около 48 единиц.
- Симуляция идёт 20 ходов в секунду (10 единиц пути за ход). Раунд — 120 секунд, 2400 ходов.
- У каждого стартовая база — круг радиусом 60 единиц. Базы стоят симметрично относительно центра поля, поэтому стороны равны.
- Пока ты на своей земле, следа нет. Покинул свою землю — за тобой тянется хвост. Вернулся на свою землю — хвост и всё, что он обвёл вместе с твоей землёй, становится твоим, в том числе земля соперника. Обведённым считается всё, до чего нельзя добраться от края поля, не пересекая твою землю и хвост.
- Пересёк хвост соперника — соперник погибает. Пересёк свой хвост — погиб сам (последние несколько единиц хвоста прямо под головой не считаются). Вылетел за край поля — погиб.
- Головы сблизились меньше чем на 20 единиц — выживает тот, кто в этот момент на своей земле; на нейтральной или чужой земле гибнут оба.
- Погиб — хвост исчезает, сгорает вся твоя земля, кроме базы. Через 3 секунды возрождаешься в центре базы с исходным курсом.
- База неприкосновенна: её нельзя захватить, она всегда твоя.
- По истечении 120 секунд побеждает тот, у кого больше доля поля. Поровну — ничья.
- Землю и хвосты движок хранит на скрытой сетке 160×100 клеток по 10×10 единиц: доля поля — это доля клеток. На экране земля рисуется гладкими контурами.
- Три карты: Диагональ, Фланги, Ближний бой — отличаются положением баз. Каждая карта играется два раунда подряд, стороны меняются каждый раунд.

## Что сдать

`bot/bot.js` — ES-модуль с искусственным интеллектом:

```js
export default {
  init(info) {},                       // необязательно, в начале каждого раунда
  tick(state) { return { turn: 0.5 }; },
};
```

`tick` возвращает одно из:

- `{ turn: t }` — доля максимального поворота за ход, от −1 до 1; положительное — по часовой стрелке на экране (к большему курсу), 0 — прямо;
- `{ heading: h }` — желаемый курс в градусах: движок сам повернёт к нему так быстро, как можно;
- просто число — то же, что `{ heading: число }`.

Что-то другое или ошибка — едешь прямо.

Бот исполняется в браузере внутри Web Worker, а в песочнице — в Node. Нельзя использовать DOM, Node-модули, сеть и внешние пакеты. Можно импортировать свои файлы из `bot/` относительными путями и `../arena/engine.js`. Модуль загружается один раз на матч, поэтому состояние между раундами матча можно хранить в переменных модуля. В турнире с доработкой модуль загружается заново перед каждым раундом.

Лимит на один `tick` — 50 мс (в первые 2 секунды раунда — 250 мс, на разгон). Не успел — этот ход едешь прямо. Около 3 секунд без ответа — бот отключается до конца матча и едет прямо.

`bot/team.json` — имя и цвета команды:

```json
{ "name": "Имя команды", "motto": "Девиз", "color": "#e8825a", "accent": "#ffe2c4" }
```

Имя до 24 символов и девиз до 80 символов покажут крупно. `color` — основной цвет команды: им арена рисует счёт, полосу территории и подписи. `accent` — второй цвет. Оба цвета приходят и в облик.

## Что видит бот

Каждый ход `tick(state)` получает всё поле, скрытого нет:

```js
{
  tick, time, timeLeft, dt, side, mapName,
  width: 1600, height: 1000, cell: 10, cols: 160, rows: 100,
  land:  Int8Array(160*100),   // клетка row*160 + col: 0 — ничья, 1 — твоя, 2 — соперника
  trail: Int8Array(160*100),   // 0 — нет хвоста, 1 — твой хвост, 2 — хвост соперника
  me: {
    x, y, heading, speed, turnRate,   // позиция, курс (градусы), 200 ед/с, 240 °/с
    alive, respawnIn,                 // жив ли; ходов до возрождения
    home,                             // стоит ли голова на своей земле
    trail: [{ x, y }],                // точки хвоста от места выхода до головы, по одной на ход
    trailCells,                       // длина хвоста в клетках
    cells, percent,                   // земля в клетках и в процентах поля
    base: { x, y, radius },
    kills, deaths,
  },
  enemy: { ...то же для соперника },
}
```

`init(info)` получает `{ round, side, mapName, view }`, где `view` — такое же состояние на старте раунда. Точные правила — в `arena/engine.js`, его можно читать и импортировать для своих расчётов (например, `sanitizeTurn`, `TURN_PER_TICK`, `STEP`).

## Облик

Арена — тёмная нейтральная сцена. Всё, что видно от твоей команды, рисует `bot/skin.js`.

```js
export default {
  draw(ctx, f) {
    // f.mode: 'arena' | 'intro' | 'victory'
  },
};
```

`draw` вызывается каждый кадр (до 60 раз в секунду) с чистым прозрачным холстом. `ctx` — Canvas 2D (`OffscreenCanvasRenderingContext2D`). Переменные модуля живут между кадрами.

### Режим `'arena'` — команда на поле

Холст размером с поле, координаты в пикселях холста (камера арены уже учтена):

```js
{
  mode: 'arena', t, dt,            // секунды с начала показа и с прошлого кадра
  width, height,                   // размер холста в пикселях
  unit,                            // пикселей в одной единице поля (меняется вместе с камерой)
  color, accent, name, motto,
  land: [Float32Array],            // контуры твоей земли: [x0, y0, x1, y1, ...], каждый замкнут;
                                   // при заливке всех контуров одним путём с правилом 'evenodd' дыры получаются сами
  base: { x, y, r },               // твоя база
  trail: Float32Array,             // точки хвоста [x0, y0, ...] от места выхода до головы (пусто, если дома)
  head: { x, y, heading, speed, alive, respawnIn, home },   // heading в градусах, speed в пикселях/с
  percent, enemyPercent, timeLeft,
  enemy: { head: { x, y, heading, alive }, color },
  events: [ ... ],                 // что случилось с прошлого кадра, приходит один раз
}
```

События:

- `{ type: 'capture', x, y, percent, cells, area }` — ты захватил землю; `area` — контуры захваченной области (как `land`), `percent` — сколько процентов поля;
- `{ type: 'kill', x, y, cause }` — соперник погиб из-за тебя;
- `{ type: 'death', x, y, cause }` — ты погиб: `cause` — `'cut'`, `'self'`, `'wall'` или `'head'`;
- `{ type: 'respawn', x, y }` — ты возродился на базе.

### Режим `'intro'` — карточка команды перед матчем

Холст примерно 840×860 логических пикселей (на 4K вдвое больше). Поля: `mode, t, dt, width, height, color, accent, name, motto`. Над карточкой арена подписывает название модели.

### Режим `'victory'` — победа в раунде и в матче

Холст 16:9 примерно 1152×648 логических пикселей в центре экрана. `t` растёт от 0, на экране около 5 секунд. Поля: `mode, t, dt, width, height, color, accent, name, motto, percent`. Имя победителя и счёт арена пишет под окном сама.

### Технические пределы облика

- Облик работает в своём Web Worker на своём холсте: он не видит страницу, движок и соперника. Нет DOM, сети и подключаемых шрифтов (текст — системными шрифтами). Можно импортировать свои файлы из `bot/`.
- Бюджет — 8 мс на кадр. Если облик часто не укладывается, бросает ошибки или зависает, его заменяют простым обликом по умолчанию до конца матча (в турнире с доработкой — до следующего раунда), бой продолжается.
- Облик не влияет на исход боя. Песочница облик не показывает.

## Раунды с доработкой

Турнир может идти в режиме доработки: после каждого раунда в папку `rounds/` этой папки записываются два файла:

- `rounds/round-N.md` — короткая сводка: итог, доля поля по времени, где и как ты погибал, что делал соперник;
- `rounds/round-N.json` — полный реплей: все повороты обеих сторон.

Разобрать реплей без браузера:

```
node arena/replay.mjs rounds/round-1.json               # сводка и карта поля каждые 30 секунд
node arena/replay.mjs rounds/round-1.json --at 47       # карта поля на 0:47
node arena/replay.mjs rounds/round-1.json --events      # все гибели и захваты
node arena/replay.mjs rounds/round-1.json --from 40 --to 43   # позиция, курс и поворот обеих сторон по ходам
```

Следующий раунд начинается со свежей загрузкой `bot/` с диска.

## Песочница

```
node arena/cli.mjs                     # bot/ против Охотника, 6 раундов: все карты с обеих сторон
node arena/cli.mjs --vs farmer         # против Пахаря
node arena/cli.mjs --vs bot            # зеркальный матч против самого себя
node arena/cli.mjs --rounds 2 --map Фланги --verbose
node arena/cli.mjs --save sandbox      # записать реплеи и сводки в sandbox/ для replay.mjs
```

Спарринг-боты лежат в `arena/sparring/`: «Пахарь» аккуратно нарезает прямоугольники, «Охотник» делает короткие вылазки и режет чужие хвосты. Нужен Node.js 18+.
