# Захват территории

Турнир один на один в духе paper.io между командами, которые целиком создают нейросети: имя, девиз, облик (земля, хвост, персонаж, эффекты, карточка команды, анимация победы) и искусственный интеллект. Сделана для ролика «Sonnet 5.5 против GPT-6.1 Sol».

Зависимостей нет, нужен только Node.js 18+.

## Как провести бой

1. Создай каждому участнику папку **вне арены**: копия `kit/` с отдельным git. Модель работает только там и не видит ни арену, ни соперника.

   ```
   node new-contestant.mjs sonnet --model "Claude Sonnet 5.5" --color "#e8825a"
   node new-contestant.mjs sol    --model "GPT-6.1 Sol"       --color "#4fc3c9"
   ```

   По умолчанию папки — `C:\arena-sonnet` и `C:\arena-sol`, другой путь — `--dir D:\где-угодно\sonnet`. Участник записывается в `arena.config.json` в корне арены (файл локальный, в git не идёт).

2. Запусти агента в его папке (`C:\arena-sonnet` — Claude Code, `C:\arena-sol` — Codex) и дай промпт из [prompts/territory-battle.md](prompts/territory-battle.md), одинаковый для обоих.

3. Когда оба закончат, запусти просмотрщик и открой http://localhost:4747:

   ```
   node serve.mjs
   ```

   «Представление и бой» показывает карточки команд, затем матч до нужного числа побед (по умолчанию до 2). После каждого раунда в папку каждого участника пишутся `rounds/round-N.json` и `rounds/round-N.md`.

Быстрый старт по ссылке: `http://localhost:4747/?a=sonnet&b=sol&first=2&auto=intro`.

В `a` и `b` можно передать и абсолютный путь к папке участника, без `arena.config.json`: `http://localhost:4747/?a=C:/arena-sonnet&b=C:/arena-sol&auto=intro`.

## Турнир с доработкой

`http://localhost:4747/?a=sonnet&b=sol&auto=tournament&rounds=3`

1. Карточки команд, пробел — раунд 1.
2. После раунда просмотрщик останавливается на экране «Время на доработку» и пишет каждому участнику в его папку `rounds/round-N.md` (сводка: итог, доля поля по времени, где и как погибал, что делал соперник) и `rounds/round-N.json` (полный реплей). Сама арена агентов не запускает.
3. Паша пишет агентам сам; пример текста — [prompts/territory-improve.md](prompts/territory-improve.md). Агент читает сводку, разбирает реплей командой `node arena/replay.mjs rounds/round-N.json` и дорабатывает команду.
4. Когда оба закончили, `N` или кнопка «Раунд 2»: просмотрщик заново читает обе команды с диска и играет следующий раунд. После последнего раунда — победитель турнира (больше побед в раундах, при равенстве больше суммарная доля поля).

Каждая карта играется два раунда подряд со сменой сторон: раунды 1-2 — «Диагональ», 3-4 — «Фланги», 5-6 — «Ближний бой».

Клавиши: пробел — старт/пауза, `1`/`2`/`3`/`4`/`0` — скорость ×1/×2/×4/×8/×0.5, `M` — звук, `F` — полный экран, `D` — пропуски ботов и состояние обликов, `N` — следующий раунд турнира, `Esc` — меню.

Параметры ссылки: `a`, `b`, `first`, `rounds`, `speed`, `auto=intro|fight|tournament`, `autostart=секунды` (сам начать бой после карточек), `debug=1`, `slow=0.25` (всё шоу в замедленном реальном времени, для покадровой записи).

## Повтор боёв из реплеев

`http://localhost:4747/?a=sonnet&b=sol&replay=sonnet&rounds=3&round=2&auto=intro&autostart=4`

Движок получает ходы из `rounds/round-N.json` участника (`replay=<id или путь к папке>`, или `replay=url:<адрес файла>` для своего реплея), боты не запускаются, файлы раундов не пишутся. Облики, камера, замедление на гибелях, «+N%», отсчёт, экран раунда работают как в живом бою; перед раундами 2+ облики загружаются заново, как в турнире; после последнего раунда турнира (`rounds`) — экран победителя. `round=2`, `1,3` или `1-3` выбирает раунды, счёт до них берётся из более ранних реплеев. После каждого раунда пересчёт сверяется с записью (итог, события, доли по секундам), результат в консоли и в `window.__replayChecks`.

Для покадровой записи: `&capture=1` (своего цикла кадров нет, кадр — `window.__cap.step()` ровно на 1/60 с; облики получают виртуальное время и засеянный `Math.random`, лимит 8 мс на кадр не применяется, реальное время рисования видно в статусе облика; звуки не играют, а пишутся в `window.__cap.sfxLog`) и `&layers=native` (слои команд и окна обликов в полном разрешении холста, без ограничений 2560 и 1920 пикселей).

## Устройство

- `kit/arena/engine.js` — правила, детерминированные и без DOM. Движение непрерывное (позиция, курс, ограниченная скорость поворота), земля и хвосты хранятся на скрытой сетке 160×100. Судья, песочница и разбор реплеев используют один и тот же код: раунд из браузера пересчитывается `replay.mjs` клетка в клетку.
- `kit/arena/report.js` — запись реплея и сводка раунда, `kit/arena/replay.mjs` — разбор реплея без браузера, `kit/arena/cli.mjs` — песочница, `kit/arena/sparring/` — спарринг-боты «Пахарь» и «Охотник» (у них нет skin.js, на них виден облик по умолчанию).
- `kit/ARENA.md` — правила, API бота и API облика для участника.
- `viewer/` — просмотрщик:
  - каждый бот в своём Web Worker: ход дольше 50 мс (в первые 2 с раунда — 250 мс) пропускается, около 3 секунд без ответа — бот отключается, матч идёт дальше;
  - каждый облик в своём Web Worker рисует свою команду целиком в каждом кадре на своём слое (OffscreenCanvas), арена только складывает слои. Бюджет 8 мс на кадр; ошибки, зависание или постоянные тормоза — облик по умолчанию, бой идёт;
  - `contours.js` превращает сетку в гладкие контуры (marching squares по размытому полю + сглаживание);
  - арена даёт операторскую работу: замедление и наезд камеры на гибелях, вспышка захваченной области и «+N%», крупный счёт и полоса территории, огромный отсчёт последних 10 секунд, экраны карточек и победителя с анимацией команды.
- `serve.mjs` — статика, список команд (`/api/bots`: спарринг, `arena.config.json` и пути из ссылки), файлы участника по адресу `/team/<id>/` и запись файлов раунда (`POST /api/round`, только в `rounds/` папки участника).
- Облик может использовать картинки из `bot/assets/` (SVG, PNG, JPEG, WebP; до 20 файлов и 2 МБ): страница растрирует их (SVG — длинная сторона 1280 пикселей) и передаёт в воркер как `f.images`. Участникам это не сообщается.
- Базы симметричны относительно центра, стороны чередуются. Зеркальный матч «Охотник против Охотника» даёт ровно поровну.

Проверка правил без браузера: `npm run sandbox` (Пахарь против Охотника) и `npm run mirror` (зеркальный матч).
