# Захват территории

Турнир один на один в духе paper.io между командами, которые целиком создают нейросети: имя, девиз, облик (персонаж, узор земли и хвоста, анимация победы) и искусственный интеллект. Сделана для ролика «Sonnet 5.5 против GPT-6.1 Sol».

Зависимостей нет, нужен только Node.js 18+.

## Как провести бой

1. Создай папку каждому участнику. Это копия `kit/` с отдельным git, чтобы модели работали независимо друг от друга.

   ```
   node new-contestant.mjs sonnet --model "Claude Sonnet 5.5" --color "#e8825a"
   node new-contestant.mjs sol    --model "GPT-6.1 Sol"       --color "#4fc3c9"
   ```

2. Запусти агента в его папке (`contestants/sonnet` — Claude Code, `contestants/sol` — Codex) и дай промпт из [prompts/territory-battle.md](prompts/territory-battle.md), одинаковый для обоих.

3. Когда оба закончат, запусти просмотрщик и открой http://localhost:4747:

   ```
   node serve.mjs
   ```

   «Представление и бой» показывает карточки команд (облик, имя, девиз), затем матч до нужного числа побед (по умолчанию до 2). После каждого раунда в папку каждого участника пишутся `rounds/round-N.json` и `rounds/round-N.md`.

Быстрый старт по ссылке: `http://localhost:4747/?a=contestants/sonnet&b=contestants/sol&first=2&auto=intro`.

## Турнир с доработкой

Зрители просили турнир, где модель учится между боями. Кнопка «Турнир с доработкой» или ссылка

`http://localhost:4747/?a=contestants/sonnet&b=contestants/sol&auto=tournament&rounds=3`

1. Карточки команд, пробел — раунд 1.
2. После раунда просмотрщик останавливается на экране «Время на доработку» и пишет каждому участнику `rounds/round-1.md` (сводка: итог, доля поля по времени, где и как погибал, что делал соперник) и `rounds/round-1.json` (полный реплей).
3. Дай обоим агентам промпт из [prompts/territory-improve.md](prompts/territory-improve.md) с номером раунда. Агент читает сводку, разбирает реплей командой `node arena/replay.mjs rounds/round-1.json` и дорабатывает бота и облик.
4. Когда оба закончили, нажми `N` или кнопку «Раунд 2»: просмотрщик заново читает обе команды с диска (bot.js, team.json, skin.js) и играет следующий раунд. После последнего раунда — победитель турнира (больше побед в раундах, при равенстве больше суммарная доля поля).

Каждая карта играется два раунда подряд со сменой сторон: раунды 1-2 — «Диагональ», 3-4 — «Фланги», 5-6 — «Ближний бой».

Клавиши: пробел — старт/пауза, `1`/`2`/`3`/`4`/`0` — скорость ×1/×2/×4/×8/×0.5, `M` — звук, `F` — полный экран, `D` — ошибки и пропуски ботов и состояние обликов, `N` — следующий раунд турнира, `Esc` — меню. Параметры ссылки: `a`, `b`, `first`, `rounds`, `speed`, `auto=intro|fight|tournament`.

## Устройство

- `kit/arena/engine.js` — правила, детерминированные и без DOM. Судья, песочница и разбор реплеев используют один и тот же код: раунд из браузера пересчитывается `replay.mjs` клетка в клетку.
- `kit/arena/report.js` — запись реплея и сводка раунда (общая для просмотрщика и CLI), `kit/arena/replay.mjs` — разбор реплея без браузера, `kit/arena/cli.mjs` — песочница, `kit/arena/sparring/` — спарринг-боты «Пахарь» (аккуратные прямоугольники) и «Охотник» (короткие вылазки, режет чужие хвосты). У спарринг-ботов нет skin.js: на них виден облик по умолчанию.
- `kit/ARENA.md` — правила и API для участника.
- `viewer/` — просмотрщик. Каждый бот работает в отдельном Web Worker: он не может трогать движок, соперника или страницу. Ход дольше 50 мс (время меряет сам воркер, поэтому тяжёлая отрисовка страницы бота не штрафует) пропускается, голова едет прямо; около 3 секунд без ответа — бот отключается, матч продолжается.
- Облик (`skin.js`) исполняется в своём Web Worker на OffscreenCanvas. Голова (4 направления × 8 кадров, портрет), плитки земли и хвоста рисуются заранее, анимация победы идёт кадрами в реальном времени. Каждый вызов с дедлайном: ошибка — этот элемент рисуется обликом по умолчанию, зависание — воркер убивается и всё оставшееся берётся по умолчанию. Бой не останавливается.
- `serve.mjs` — статика, список команд (`/api/bots`) и запись файлов раунда (`POST /api/round`, только в `contestants/<имя>/rounds/`).
- Поле 64×40, 10 ходов в секунду, раунд 120 секунд. Базы симметричны относительно центра, стороны чередуются. Зеркальный матч «Охотник против Охотника» даёт ровно поровну.

Проверка правил без браузера: `npm run sandbox` (Пахарь против Охотника) и `npm run mirror` (зеркальный матч).
