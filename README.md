# Захват территории

Турнир один на один в духе paper.io между командами, которые целиком создают нейросети: имя, девиз, облик (земля, хвост, персонаж, эффекты, карточка команды, анимация победы) и искусственный интеллект. Сделана для ролика «Sonnet 5.5 против GPT-6.1 Sol».

Зависимостей нет, нужен только Node.js 18+.

## Как провести бой

1. Создай папку каждому участнику. Это копия `kit/` с отдельным git, чтобы модели работали независимо друг от друга.

   ```
   node new-contestant.mjs sonnet --model "Claude Sonnet 5.5" --color "#e8825a"
   node new-contestant.mjs sol    --model "GPT-6.1 Sol"       --color "#4fc3c9"
   ```

2. Запусти агента в его папке (`contestants/sonnet` — Claude Code, `contestants/sol` — Codex) и дай промпт из [prompts/territory-battle.md](prompts/territory-battle.md), одинаковый для обоих.

3. Когда оба закончат, запусти просмотрщик и открой http://localhost:4747:

   ```
   node serve.mjs
   ```

   «Представление и бой» показывает карточки команд, затем матч до нужного числа побед (по умолчанию до 2). После каждого раунда в папку каждого участника пишутся `rounds/round-N.json` и `rounds/round-N.md`.

Быстрый старт по ссылке: `http://localhost:4747/?a=contestants/sonnet&b=contestants/sol&first=2&auto=intro`.

## Турнир с доработкой

`http://localhost:4747/?a=contestants/sonnet&b=contestants/sol&auto=tournament&rounds=3`

1. Карточки команд, пробел — раунд 1.
2. После раунда просмотрщик останавливается на экране «Время на доработку» и пишет каждому участнику `rounds/round-N.md` (сводка: итог, доля поля по времени, где и как погибал, что делал соперник) и `rounds/round-N.json` (полный реплей). Сама арена агентов не запускает.
3. Паша пишет агентам сам; пример текста — [prompts/territory-improve.md](prompts/territory-improve.md). Агент читает сводку, разбирает реплей командой `node arena/replay.mjs rounds/round-N.json` и дорабатывает бота и облик.
4. Когда оба закончили, `N` или кнопка «Раунд 2»: просмотрщик заново читает обе команды с диска (bot.js, team.json, skin.js) и играет следующий раунд. После последнего раунда — победитель турнира (больше побед в раундах, при равенстве больше суммарная доля поля).

Каждая карта играется два раунда подряд со сменой сторон: раунды 1-2 — «Диагональ», 3-4 — «Фланги», 5-6 — «Ближний бой».

Клавиши: пробел — старт/пауза, `1`/`2`/`3`/`4`/`0` — скорость ×1/×2/×4/×8/×0.5, `M` — звук, `F` — полный экран, `D` — пропуски ботов и состояние обликов, `N` — следующий раунд турнира, `Esc` — меню.

Параметры ссылки: `a`, `b`, `first`, `rounds`, `speed`, `auto=intro|fight|tournament`, `autostart=секунды` (сам начать бой после карточек), `debug=1`, `slow=0.25` (всё шоу в замедленном реальном времени, для покадровой записи).

## Устройство

- `kit/arena/engine.js` — правила, детерминированные и без DOM. Движение непрерывное (позиция, курс, ограниченная скорость поворота), земля и хвосты хранятся на скрытой сетке 160×100. Судья, песочница и разбор реплеев используют один и тот же код: раунд из браузера пересчитывается `replay.mjs` клетка в клетку.
- `kit/arena/report.js` — запись реплея и сводка раунда, `kit/arena/replay.mjs` — разбор реплея без браузера, `kit/arena/cli.mjs` — песочница, `kit/arena/sparring/` — спарринг-боты «Пахарь» и «Охотник» (у них нет skin.js, на них виден облик по умолчанию).
- `kit/ARENA.md` — правила, API бота и API облика для участника.
- `viewer/` — просмотрщик:
  - каждый бот в своём Web Worker: ход дольше 50 мс (в первые 2 с раунда — 250 мс) пропускается, около 3 секунд без ответа — бот отключается, матч идёт дальше;
  - каждый облик в своём Web Worker рисует свою команду целиком в каждом кадре на своём слое (OffscreenCanvas), арена только складывает слои. Бюджет 8 мс на кадр; ошибки, зависание или постоянные тормоза — облик по умолчанию, бой идёт;
  - `contours.js` превращает сетку в гладкие контуры (marching squares по размытому полю + сглаживание);
  - арена даёт операторскую работу: замедление и наезд камеры на гибелях, вспышка захваченной области и «+N%», крупный счёт и полоса территории, огромный отсчёт последних 10 секунд, экраны карточек и победителя с анимацией команды.
- `serve.mjs` — статика, список команд (`/api/bots`) и запись файлов раунда (`POST /api/round`, только в `contestants/<имя>/rounds/`).
- Базы симметричны относительно центра, стороны чередуются. Зеркальный матч «Охотник против Охотника» даёт ровно поровну.

Проверка правил без браузера: `npm run sandbox` (Пахарь против Охотника) и `npm run mirror` (зеркальный матч).
